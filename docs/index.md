# College Alumni API Documentation

Welcome to the documentation portal for the **College Alumni Application**.

This portal provides structured API documentation, setup instructions, architecture details, versioning strategy, and API reference pages for the alumni platform.

## Project Purpose
The goal of this project is to create a centralized documentation system for the alumni application using:
- OpenAPI Specification
- Swagger UI
- Redoc
- MkDocs
- GitHub branch-based documentation workflow

## Main Features Covered
- User authentication
- Alumni profile management
- Alumni directory and filtering
- Mentorship workflows
- Events and webhook notifications
- Community features like donations, messaging, FAQs, and jobs

## Documented APIs
- Auth API
- Alumni Profile API
- Directory API
- Events API
- Mentorship API
- Alumni Community API

## Documentation Objectives
- Maintain development and release documentation separately
- Standardize API contracts using OpenAPI
- Provide interactive API exploration through Swagger UI
- Organize project docs in a readable portal using MkDocs

## Branch Strategy
- `develop-docs` → design and development phase APIs
- `release-docs` → approved and published APIs
