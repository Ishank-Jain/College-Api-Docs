# Getting Started

This guide helps you understand the purpose and basic usage of the College Alumni API documentation project.

## What this repository contains
This repository contains:
- OpenAPI YAML specifications
- Swagger UI configuration
- Redoc configuration
- MkDocs documentation pages
- CI/CD and deployment-ready structure

## Documentation Stack
- **OpenAPI 3.0.3** for API contracts
- **Swagger UI** for interactive API testing
- **Redoc** for clean API reference rendering
- **MkDocs** for full documentation portal

## Main API Groups
- Auth API
- Alumni Profile API
- Directory API
- Events API
- Mentorship API
- Alumni Community API

## Documentation Workflow
1. API is first designed in the development branch
2. OpenAPI YAML is created or updated
3. Swagger and Redoc are used for API rendering
4. MkDocs pages are updated
5. Stable versions are moved to release documentation

## Recommended Understanding Order
1. Read `api-overview.md`
2. Read `authentication.md`
3. Read `versioning.md`
4. Read `architecture.md`
5. Open each API reference page
